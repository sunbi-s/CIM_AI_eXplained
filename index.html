I. Introduction

Learning through interaction with an environment is a common intelligent behavior easily observed in humans or animals. Generally, they recognize the surrounding environment or state and take action based on their understanding. As a result of actions, feedback is given, and they learn from it. Reinforcement learning (RL) is a computational approach based on this learning mechanism. Recently RL showed impressive results in various domains, such as Go[1], StarCraft[2], protein-folding problem[3], etc.

RL consists of four main elements:

  • Policy: a probability distribution of actions in a given state. It determines the agent’s behavior.
  • Reward: a signal that is given to an agent based on its behavior or actions in an environment. The reward serves as a way to reinforce or encourage certain behaviors and discourage others. It determines a goal in an RL problem.
  • Value function: the total amount of reward that an agent will get in the future, starting from a specific state. It shows how good a state is in the long run.
  • Model of the environment: a model that makes predictions of the environment’s behavior, thereby enabling inference about how the environment will behave.

Reinforcement learning is a type of artificial intelligence that allows an agent to learn how to make decisions in an environment by trial and error. In each step, the agent's policy decides on an action based on the current state. The environment then responds with a next state and a reward. If the agent reaches the terminal state, the episode ends. To improve its decision-making, the agent's policy can be updated based on the value function, which estimates the value of a state or action. However, obtaining the correct value function can be challenging since the agent must predict future rewards without actually visiting all possible future states.

There are two types of reinforcement learning algorithms: model-free and model-based. Model-free algorithms estimate the value function from many trials and update the policy based on the values. Model-based algorithms, on the other hand, compute the values of states by considering all possible future states and actions using the model of the environment.

In this article, we will focus on two fundamental model-free algorithms: Monte Carlo and Temporal Difference. These algorithms are powerful tools for solving a variety of reinforcement learning problems. We will train and evaluate the agents on grid-based environment. II. Markov Decision Process

Reinforcement learning is a widely-used methodology in machine learning that focuses on solving sequential decision-making problems. In these types of problems, the decisions made at the current step have an impact on future outcomes. One of the most popular ways to formalize this process is through the Markov decision process (MDP), which provides a useful framework for representing and solving sequential decision-making problems.

MDPs are defined by a set of states, actions, transition probabilities, and rewards that govern how the system moves from one state to another based on the decisions made by the agent. It is crucial to understand MDP because the goal of reinforcement learning is to find an optimal policy that maximizes rewards, or evaluate the value of a set of actions given MDP's rules and constraints. MDP extends the concept of a Markov process, which is a stochastic process that only consists of states and transition probabilities.

Markov Process

A Markov process is a stochastic process that describes a system in which the state of the system changes over time. At each time step, the state may remain the same or transition to a different state, based on the probability of transition that depends solely on the current state. This property is known as the Markov property, where the future state of the system is determined only by the present state and not by any previous states. An example[4] of a Markov process is shown in Figure3.

There are five possible states that a child can be in, including \(s_0\)(Lying), \(s_1\)(Awake), \(s_2\)(Drowsy), \(s_3\)(Light Sleep), and \(s_4\)(Deep Sleep). Each state lasts for a unit of time, such as one minute, and transitions to the next state based on certain probabilities. Assuming the markov process always starts with the child \(s_0\)(Lying), the child remains in this state for one minute. After that, there is a 40% probability of transitioning to \(s_1\)(Awake) or a 60% probability of transitioning to \(s_3\)(Light Sleep). The process continues until the child reaches \(s_4\)(Deep Sleep) , which ends the Markov Process.

Here are the components that make up a Markov Process:

  • State Space (\(S\)): All possible states that the system can take, such as Deep sleep, Light sleep, Drowsy and Awake, represented as \(\{s_0, s_1, s_2, s_3, s_4\} \in S\).
  • Transition Probability(\(P_{ss'}\)): The probability of transitioning from state \(s\) to another state \(s'\) at step \(t\), represented as \(P_{ss'} = P(S_{t+1} = s' \mid S_{t} = s)\).

Markov Decision Process

The Markov Decision Process (MDP) extends the Markov Process by incorporating decision-making capabilities, which sets it apart from the latter. While the Markov Process models a system where the future state is determined only by the current state, the MDP introduces the concept of actions taken by an agent that can influence the next state of the system. This enables the MDP to better model real-world scenarios.

In an MDP, at each time step, the agent chooses an action based on its current state and the reward associated with the action. The chosen action then determines the probability of transitioning to the next state. The agent's goal is to learn a policy, which is a mapping of states to actions that maximizes the expected cumulative reward over time. By making decisions based on this policy, the agent can navigate the system and achieve its objectives efficiently. Figure 5 provides an example of an MDP.

Here are the components that make up a Markov Decision Process:

  • State Space (\(S\)): All possible states that the system can take, represented as \(\{s_0, s_1, s_2, s_3, s_4\} \in S\).
  • Action Space(\(A\)): All possible actions that can be taken given a state \(s\), including singing a lullaby and playing with the child, represented as \(\{a_0, a_1\} \in A\).
  • Transition Probability(\(P_{ss'}^a\)): The probability of transitioning from state \(s\) to another state \(s'\) after taking action \(a\) at step \(t\), represented as \(P_{ss'}^a = P(S_{t+1} = s' \mid S_{t} = s, A_{t}=a)\).
  • Reward function(\(R\)): The reward function in this MDP can evaluate the desirability of different actions by providing scalar value called Reward(\(R_t)\) given step \(t\).
  • Discount Factor(\(\gamma\)): It is a value between 0 and 1 that determines the importance of immediate rewards versus long-term rewards.

Markov Decision Processes (MDPs) differ from Markov Processes in that they include a goal through reward. In the context of helping a child sleep, a reward function can be set to encourage good sleeping patterns. Alternatively, if the objective is to play with the child, MDPs may reward being awake. The goal of MDPs is to determine which action to select in each state to maximize the sum of rewards.

For instance, \(a_0\)(Playing with child) in the \(s_0\)(Lying) immediately transitions to the state \(s_1\)(Awake) and receives positive rewards. However, in the long term, continuous \(a_1\)(Singing a lullaby) to put the child to sleep will yield the highest reward. Interestingly, If playing with child action is taken while the child is \(s_2\)(Drowsy), depending on the given probability, it may transition to an awake state or a lying state. This transition probability helps to model more realistic problems.

To maximize the sum of rewards(\(R_t\)) by time(\(t\)) in an MDP, it is necessary to evaluate the value of each state and determine which action to take in each state(\(s\)). The value of a state is determined by the expected sum of discounted future rewards that can be obtained by taking a particular action in that state. The discounting factor(\(\gamma)\) is used to ensure that immediate rewards are valued more highly than delayed rewards. This expected sum of future rewards is called the return(\(G_t\)).

However, since the return value changes every time due to probabilistic factors such as transitions, the expected value of the return must be used. A function that outputs the expected return value for each state is called the value function\(v_\pi\). The value function is a critical concept in reinforcement learning as it enables an agent to evaluate the value of different states and determine the optimal policy to follow to maximize rewards. \[V(s) = \mathbb{E}\left[G_t \mid S_t=s\right]=\mathbb{E}\left[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \mid S_t=s\right], \text { for all } s \in \mathcal{S}\]

In a model-free environment, the transition probability and reward function are not known. Therefore, they must be estimated from experience. There are two primary methods for estimating the value function in a model-free environment: the Monte Carlo (MC) method and the Temporal Difference (TD) method.

The SharkGame can be viewed as a Markov Decision Process where the states represent the position of the shark character and the actions are moving up, down, left, or right. This approach encourages the agent to find the shortest path to the goal while avoiding obstacles. The consequently learned policy is to select actions that lead to the transition to the state with the maximum value.

III. Monte Carlo approach

Monte Carlo estimate the values by simply averaging sample returns. The Monte Carlo method is based on simulating a number of episodes of an agent interacting with the environment. In each episode, the agent takes actions and receives rewards, and the sequence of states, actions, and rewards is recorded. The final outcome of each episode is used to update the value of each state. The Monte Carlo approach estimates the value of a state as the average of the returns received in all the episodes in which that state was visited. The return is the sum of rewards received after visiting that state until the end of the episode. The estimated value of a state becomes more accurate as the number of episodes increases.

After each episode, sample return $$G_t$$ is computed by each step.

$$G_t = R_{t+1} + \gamma R_{t+2} + ... + \gamma^{T-1} R_{T}$$

Then for each visited state in the episode, the increment counter $$N(s)$$ (which refers the number of visits to state $$s$$) increased by 1 and the sample return $$G_t$$ is added to total return $$S(s)$$, and finally dividing $$S(s)$$ by $$N(s)$$, the state value $$V(s)$$ is obtained.

\[N(s) = N(s) + 1\] \[S(s) = S(s) + G_t\] \[V(s) = S(s) / N(s)\]

There are a few disadvantages of the Monte Carlo approach. One disadvantage is that Monte Carlo requires complete episodes of interaction with the environment before updating the values of states. This can be time-consuming and computationally expensive, especially in problems where episodes are long or infinite. In addition, Monte Carlo can suffer from high variance in the estimates of values, particularly when episodes are short or few. This variance can make it difficult for the agent to learn the true values of states, and can lead to slower convergence. Following Temporal Difference approach addresses this issues, making it more stable and efficient in learning the values.

IV. Temporal Difference learning

Temporal Difference (TD) is another method for estimating the value function in reinforcement learning. Unlike Monte Carlo (MC) methods, which require waiting until the end of an episode to update the value function, TD updates the value function at every transition. MC methods require the complete return of an episode to update the value function. However, the return cannot be known until the end of the episode. This waiting time can be avoided by using TD, which updates the value function before the end of an episode.

TD achieves this goal by using the Bootstrap method, which updates an estimate using another estimate. Specifically, TD uses the difference between observed rewards and predicted rewards to update the value function estimate at each time step. This allows TD to update the value function estimate incrementally and in real-time, without the need to wait for the end of an episode. \[v_\pi\left(s_t\right)=\mathbb{E}_\pi\left[r_{t+1}+\gamma v_\pi\left(s_{t+1}\right)\right]\]

Compared to MC methods, TD has the advantage of being more computationally efficient. However, it may have bias and may not converge to the true value function. Despite this limitation, TD has been successfully applied in a wide range of reinforcement learning problems.

V. Difference between MC and TD

Both MC and TD approaches are used in reinforcement learning to estimate the value function, but they differ in how they update this function. Monte Carlo estimates values by averaging the sample returns obtained from multiple episodes, while TD uses the Bellman equation to compute target values from estimated values. This means that MC can update values only at the end of each episode, while TD can update values after each time step. Therefore, MC can be more computationally expensive and time-consuming, whereas TD is more efficient and faster to converge.

From a machine learning perspective, we can consider the bias and variance of these two algorithms. MC learning has low bias but high variance because it estimates the value function by averaging the returns from multiple episodes, which can lead to high variance. However, since the value function is updated only with the sample returns, there is no bias introduced by bootstrapping. On the other hand, TD learning has low variance but high bias because it updates the value function at each time step based on the difference between the observed reward and the predicted reward. This leads to lower variance since each update is based on a single time step, but it can introduce bias since the predicted reward is estimated based on the value function, which itself may be biased.

In practice, the choice between MC and TD depends on the specific problem and the available resources. If the episodes are short and the rewards are delayed, TD may be more suitable as it can update values after each time step. If the episodes are long and the rewards are immediate, MC may be a better choice as it can update values at the end of each episode. By understanding the differences between MC and TD, researchers and practitioners can choose the most appropriate approach for their particular application.

V. Conclusion

In conclusion, this paper has provided an overview of two popular approaches in reinforcement learning: Monte Carlo and Temporal Difference. While these methods have their respective advantages and disadvantages, it is worth noting that there are many other approaches to reinforcement learning beyond MC and TD. For example, model-based[5] and policy gradient methods[6] are also commonly used in this field. These other methods may be better suited to certain types of problems or have particular advantages in different contexts.

Moreover, recent advancements in the field of reinforcement learning have demonstrated the potential for combining reinforcement learning with deep learning to achieve even better results [7]. These hybrid approaches have shown promise in a wide range of applications, from game-playing and robotics to natural language processing and recommendation systems. As the field continues to evolve, it is likely that we will see more innovations and breakthroughs in the area of reinforcement learning, and it will be exciting to see how these new approaches and techniques can be applied to address real-world challenges.
